# Mall 관리 / 스크래핑 설정 — 컬럼·필수값·선택 UX 개선 모음

여러 차례에 걸친 관련 요청을 하나로 정리한 기록 (2026-07-18).

## 1. 병합 일시 컬럼 + 스크랩 Raw 확인 거래처/몰 컬럼

> "스크랩Raw확인 메뉴의 하단 '선택병합' 이름을 '확정 (스크랩검수 후)'으로 바꿔줘..." 이후 →
> "스크랩 Raw 확인에도, 거래처, 몰 컬럼을 넣어줘. 그리고 병합을 했다면 병합한 일시도 컬럼으로 표시해줘."

- `scrape_sessions.merged_at TIMESTAMPTZ` 신설. `/api/sessions/merge`가 병합 시 `NOW()`로 기록하고,
  `/api/sessions/split`은 분할(또는 그룹 완전 해체) 시 다시 비운다 — [[scrape-session-grid-and-merge-spec]]의
  `merge_group_id`와 같은 생애주기를 공유한다.
- `ScrapeSessionGrid`에 "병합 일시" 컬럼 추가 — 이 컴포넌트를 공유하는 모든 화면(데이터 마이그 목록,
  마이그레이션 하위 메뉴, 스크랩 Raw 확인, Transform)에 자동 반영됨.
- `ProductsListPanel`(스크랩 Raw 확인)의 세션 목록에도 `showClientMall`을 켜 거래처/몰 컬럼을 노출.

## 2. 거래처 관리 그리드 — 다른 그리드와 동일한 조작성

> "거래처 관리 메뉴의 그리드도 하단의 그리드와 같이 똑같이 수정해줘."

`ClientsListPanel.tsx`의 거래처 목록 테이블에 StagingItemsGrid/ScrapeSessionGrid와 동일한 컬럼 클릭 정렬
(Shift+클릭 복합 정렬), 컬럼별 필터, 컬럼 폭 드래그 조절, 헤더 드래그 순서 변경을 추가. 기존에 거래처명
컬럼에 걸려있던 `sticky left-0` 고정 처리는 컬럼 순서를 자유롭게 바꿀 수 있게 하면서 의미가 없어져
제거함(다른 그리드들도 고정 컬럼 없이 동작).

## 3. Mall 이름 필수값 + 메인 품목 컬럼

> "Mall 관리 메뉴에 그리드 컬럼의 '이름'을 'Mall 이름'으로 변경하고 바로 뒤에 '메인 품목'컬럼을 넣어줘.
> 여기에는 Mall등록 시 주요 판매 품목을 기입하는 용도야." 이후 → "Mall 등록 메뉴에서 mall 이름은
> 필수값으로 해줘."

- `sites.main_items TEXT` 신설 — Mall 등록/수정 화면(SiteDetailPanel)에 "메인 품목" 입력란 추가, 목록
  그리드에 "Mall 이름" 바로 뒤 컬럼으로 노출.
- `sites.name`을 `NOT NULL`로 변경 — 기존 데이터에 빈 이름이 없는 것을 확인한 뒤 적용(URL 컬럼과 동일한
  수준의 필수값). UI(저장 전 alert)와 API(POST/PUT 400 응답) 양쪽에서 검증하고, DB 제약도 걸어 3중으로
  방지.

## 4. 스크래핑 설정 — 거래처/몰 그리드 + 드롭다운 직접 선택

> "스크랩핑 설정 메뉴 관련, 상단에 Mall선택은 그리드 형태로하고, 거래처/몰을 선택하면 아래로 스크래핑
> 할 수 있게 해줘." → "Mall 선택 부분에서 바로 거래처/몰을 선택할 수 있게 수정해" → "변경 눌러서
> 들어가지 않고도, 스크래핑 설정 메뉴에서 바로 거래처/몰을 선택 바로 하게 해줘."

`ScraperPanel`의 Mall 선택 영역을 반복적으로 다듬은 결과:
- 거래처 드롭다운(필터) + 몰 드롭다운(직접 선택, 고르면 바로 `selectSite()`) + 검색창을 한 줄에 배치.
- 그 아래 헤더가 있는 그리드(Mall 이름/메인 품목/거래처/URL)로 행 클릭으로도 선택 가능.
- 몰이 이미 선택된 상태에서도 "변경" 버튼 뒤에 숨기지 않고 위 선택 UI를 항상 그대로 노출 — 현재 선택은
  그 아래 작은 요약 카드로만 보여주고 선택 자체를 막지 않는다. 즉 언제든 드롭다운/그리드로 바로 다른
  몰로 바꿀 수 있다.

## 5. 거래처 관리 — 행 클릭 시 스크래핑 메뉴로 (Mall 상세관리와 동일한 패턴)

> "거래처관리 메뉴도 Mall상세관리 메뉴처럼... mall상세관리 처럼 행을 클릭하면 바로 스크래핑 메뉴로
> 넘어가게 해줘."

"관리" 컬럼(수정/삭제)은 2번 항목의 그리드 개선 때 이미 추가돼 있었음 — 이번엔 행 클릭 동작만
`openDetail`(수정 화면 열기)에서 `openScraper`(스크래핑 탭을 `clientId` 파라미터와 함께 열기)로 변경.
`ScraperPanel`은 `params.clientId`를 받으면 거래처 드롭다운을 그 값으로 미리 채우고(이전 세션 복원은
건너뜀), 사용자가 몰만 고르면 되게 한다. "수정" 버튼은 그대로 `openDetail`을 호출해 편집 화면으로 간다.

## 6. 거래처 관리 — 결제 정보(결제자명/결제수단/통장) 복수 등록 (2026-07-21)

> "거래처관리 메뉴에 '결제자 이름, 결제 수단, 결제 통장' 정보를 등록할 수 있는 입력란을 만들어줘.
> 플러스를 눌러서 복수로 등록할 수 있게 해줘." 이후 → "거래처 관리 화면과 거래처 수정 화면의 등록
> 내용을 맞춰야지?"

- `supply_clients.payment_accounts JSONB DEFAULT '[]'` 신설 —
  `[{ payerName, paymentMethod, bankAccount }]` 배열.
- `ClientDetailPanel.tsx`에 "결제 정보" 카드 추가 — 행마다 결제자명/결제수단/통장 3개 입력 + 삭제
  버튼, "➕ 결제 정보 추가"로 행 반복 추가. 저장 시 세 값이 모두 빈 행은 제외하고 저장.
- `ClientsListPanel.tsx` 목록 그리드에도 같은 데이터를 `결제자/수단/통장` 슬래시 구분 요약으로 보여주는
  "결제 정보" 컬럼 추가 — 상세/목록 화면 표시 내용을 일치시킴(2번 항목과 같은 원칙).

## 7. 스크래핑 설정 — Mall 선택 그리드에 필터/정렬/리사이즈 추가 (2026-07-21)

> "몰관리 메뉴의 그리드와 같이 스크래핑설정 메뉴의 Mall선택 그리드도 동일하게 필터 등의 기능을
> 넣어줘"

4번 항목에서 만든 `ScraperPanel`의 Mall 선택 그리드(Mall 이름/메인 품목/거래처/URL)에, 2번 항목에서
거래처 관리 그리드에 넣었던 것과 동일한 컬럼 클릭 정렬·컬럼별 필터·폭 드래그 조절·헤더 드래그 순서
변경을 그대로 적용. 거래처/검색어 드롭다운 필터로 이미 좁혀진 목록(`filteredSites`) 위에서 추가로
컬럼 필터·정렬이 적용되는 구조.

## 검증

각 항목 진행 시 `npx tsc --noEmit`/`npx eslint` 통과 확인. 스키마 변경(merged_at, main_items, name
NOT NULL, payment_accounts)은 실제 테스트 데이터로 생성→조회→수정→삭제까지 curl로 직접 확인 후
정리했다.
