# 스크래핑 화면 — 카테고리 전체선택/미리보기 그리드 개선

## 배경

카테고리 불러오기 결과 체크리스트와 미리보기 결과 개수 그리드에서 두 가지 요청이 있었다.

## 수정 1 — 전체선택이 "제외" 표시한 카테고리까지 같이 선택하던 문제

카테고리 목록에서 실제 상품이 없는 항목(안내/게시판 페이지 등)을 "제외"로 표시해두는 기능이 있는데,
전체선택 체크박스(`toggleAllCategories`)와 그 체크 상태 판정은 `excludedCategoryHrefs`를 전혀 안 보고
`categories` 전체를 기준으로 계산했다 — "제외"를 눌러둬도 전체선택을 누르는 순간 다시 스크랩 대상으로
딸려 들어갔다.

`components/panels/ScraperPanel.tsx`: 제외된 카테고리를 뺀 `selectableCategories`를 만들어, 전체선택
클릭/체크 상태 판정 둘 다 이 목록만 기준으로 삼도록 고쳤다.

## 수정 2 — 카테고리별 미리보기 개수 그리드에서 링크를 바로 열 수 있게

"카테고리별 상품 개수" 미리보기 그리드는 카테고리명이 텍스트로만 표시돼, 그 카테고리 페이지를 직접
확인하려면 URL을 따로 복사해야 했다. 이미 있던 `handleOpenItem`(로그인 창에 새 탭 → 저장된 쿠키로 새
창 → 기본 브라우저 순으로 폴백)을 그대로 재사용해, 카테고리명을 클릭하면 바로 그 페이지가 열리도록
했다(개별 미리보기 상품 항목의 "열기" 링크와 동일한 방식).
