# 스크랩 Raw 확인 — "선택한 것만 보기" 토글

## 배경
선택한 상품이 몇 개 안 되는데 그리드 전체(세션에 따라 수십~수백 건)가 화면을 다 차지해서, 그 아래
비교 카드 등이 안 보인다는 요청. 켜면 선택된 행만 남기고 나머지는 숨기고, 꺼면 즉시 전체가 다시 보이는
토글로 구현했다.

## 구성
- `components/panels/shared/StagingItemsGrid.tsx`에 `showOnlySelected` 상태 추가. `filteredItems`(검색/이슈
  필터 적용 후) 다음, `visibleItems`(정렬) 이전 단계에 `selectionFiltered` 필터를 끼워 넣었다 — 켜져 있으면
  `selected`에 있는 id만 남긴다.
- 선택이 전부 풀리는 지점(전체선택 토글 끄기, 확정, 선택 무시, 세션/몰 범위 변경)마다 같이 꺼서, 그리드가
  텅 빈 채 남지 않게 한다.
- 체크박스는 기존 "전체 선택"/"누락된 데이터만"/"이미 가공된 상품도 포함" 옆에 네 번째 항목으로 추가.

## 실사용 검증 중 발견한 기존 버그 (같이 수정)
네 체크박스가 전부 **하나의 공유 `<label>`** 안에 `<span>`으로만 감싸여 있었다 — HTML에서 한 `<label>`이
여러 개의 폼 컨트롤을 감싸면, 어느 컨트롤이 그 라벨과 "연결"되는지가 모호해져 텍스트를 클릭하면 첫 번째
컨트롤(이 경우 "전체 선택")이 대신 토글되는 문제가 있었다. Playwright로 실제 클릭 테스트를 해보다가
발견함 — "선택한 것만 보기" 텍스트를 클릭했더니 대신 "전체 선택"이 켜졌다.

**수정**: 바깥 `<label>`을 `<div>`로 바꾸고, 각 체크박스+텍스트 쌍을 자기만의 `<label>`로 감쌌다. 네
체크박스 전부(기존 3개 + 신규 1개) 이제 각자의 텍스트를 클릭해도 정확히 자기 자신만 토글된다. 이 버그는
오늘 추가한 체크박스뿐 아니라 기존 3개에도 항상 있었던 문제였다.

## 검증
Playwright(`chromium`, 로그인 → 스크랩 Raw 확인 → 세션 선택 → 행 3개 체크 → 토글 on/off)로 실제 화면에서
확인. 라벨 버그를 고치기 전엔 토글 클릭이 "전체 선택"을 잘못 건드리는 것까지 재현했고, 고친 후 정확히
선택된 3개만 남았다가 꺼면 전체 31개로 복원되는 것, 개수 힌트("전체 31개 중 3개 표시")도 정확한 것까지
스크린샷으로 확인했다. 확정/선택 무시가 토글을 다시 끄는지는 코드 리뷰로만 확인(실제 DB 데이터를 지우는
동작이라 라이브 테스트는 하지 않음).
